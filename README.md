# Awesome-AI-Image-Processing-Pixel-Art

## Top AI Image Processing & Pixel Art Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on AI Pixel Art Synthesis & Quantization, Sprite Sheet Editors, Pixel-Grid Restoration, AI Photo Processing & Creative Retouching*  

**Last updated: November 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **AI Image Processing & Pixel Art**. These tools generate crisp pixel-art sprites and tilemaps from text or reference imagery, snap blurry AI outputs onto true pixel grids (`Proper Pixel Art`), provide full-featured pixel animation editors, and automate photo retouching and batch image processing.



**Examples** include Pixelmator Pro, Adobe Photoshop Web, Canva, Photopea, Fotor, Pixlr, BeFunky, Polarr, Luminar Neo, Photoroom, and augusto-scarvalho/claude-pxl (the category leaders). 



**Open-source emphasis**: This section is heavily expanded with every major active project for Claude Code pixel-art generation skills (`claude-pxl`), dedicated pixel-art & sprite editors (`LibreSprite`, `Pixelorama`, `Piskel`, `Aseprite` source), neural pixel-art grid restoration & diffusion models (`Proper-Pixel-Art`, `PixelArt-Diffusion`, `ComfyUI-PixelArt`), and open-source raster/batch image processors (`GIMP`, `Krita`, `ImageMagick`, `Sharp`) — ideal for indie game developers, pixel artists, creative coders, and computer vision builders.

## SaaS/Hosted Platforms



- **[Pixelmator Pro (Apple)](https://pixelmator.com)**  

  Hardware-accelerated image editing and graphic design suite featuring ML Super Resolution, AI background removal, color matching, and pixel-level raster/vector workflows.



- **[Adobe Photoshop Web (Firefly)](https://adobe.com)**  

  Cloud-based version of Photoshop offering browser-native Generative Fill, Generative Expand, Remove Tool object cleanup, and non-destructive layer compositing.



- **[Photopea](https://photopea.com)**  

  Advanced browser-native raster, vector, and pixel-art image editor with full PSD/XCF/Sketch compatibility, indexed palette tools, and AI magic replace/cutout features.



- **[Canva (Magic Studio)](https://canva.com)**  

  All-in-one cloud visual design and image processing platform featuring Magic Eraser, Magic Edit, Background Remover, and AI pixel-art/illustration generators.



- **[Photoroom](https://photoroom.com)**  

  AI photo editing and e-commerce image processing platform specializing in instant subject segmentation, studio background synthesis, batch relighting, and magic retouching.



- **[Luminar Neo (Skylum)](https://skylum.com)**  

  AI-powered creative photo editor built for photographers featuring Relight AI, Sky AI replacement, GenErase object removal, and high-resolution RAW processing.



- **[Pixlr](https://pixlr.com)**  

  Cloud photo editing and pixel-level graphic design suite offering browser-based AI generative fill, object removal, auto-cutout, and quick social templates.



- **[Fotor](https://fotor.com)**  

  Cloud photo retouching and AI art platform providing one-click photo enhancement, background removal, batch processing, and AI pixel-art style converters.



- **[Polarr](https://polarr.com)**  

  Cross-platform AI photo editing, custom LUT/filter creation, and face-aware retouching studio for web, desktop, and mobile creators.



- **[BeFunky & PixelLab / Retro Diffusion Cloud](https://befunky.com)**  

  Browser-based creative photo editors alongside specialized cloud AI pixel-art generators built for game sprites, tilesets, and palette-locked retro graphics.





## Open-Source GitHub Projects



- **[augusto-scarvalho/claude-pxl](https://github.com)**  

  Open-source AI pixel-art generation skill and workflow for Claude Code designed to author, refine, and export clean, grid-aligned pixel art sprites and retro game assets directly from prompts.



- **[LibreSprite (`LibreSprite/LibreSprite`)](https://github.com)**  

  Free and open-source (`GPL-2.0`) animated sprite editor and pixel-art creation tool (forked from the last GPL release of Aseprite) featuring onion skinning, tilemaps, and indexed color palettes.



- **[Pixelorama (`Orama-Interactive/Pixelorama`)](https://github.com)**  

  Modern, cross-platform open-source (`MIT`) 2D sprite editor, pixel-art studio, and frame-by-frame animator built with Godot Engine featuring custom brushes, tile mode, and shader effects.



- **[Piskel (`piskelapp/piskel`)](https://github.com)**  

  Popular open-source (`Apache-2.0`) browser-based and offline desktop editor for animated sprites and pixel art with live preview, onion skinning, and sprite-sheet/GIF export.



- **[Aseprite (`aseprite/aseprite`)](https://github.com)**  

  Industry-standard animated sprite editor and pixel-art tool with publicly available source code (`EULA`) allowing developers to compile custom builds and script Lua extensions.



- **[Proper-Pixel-Art (`KennethJAllen/proper-pixel-art`)](https://github.com)**  

  Open-source (`MIT`) computer-vision algorithm that converts noisy, misaligned AI-generated "faux pixel art" images back onto true, crisp pixel grids with clean color palettes.



- **[ComfyUI-PixelArt / Astropulse PixelDetector (`Astropulse/pixeldetector`)](https://github.com)**  

  Open-source neural and algorithmic pixel-art grid detection, downscaling, and palette quantization tools for turning high-res renders or diffusion outputs into authentic pixel art.



- **[Lospec Pixel Editor / GrafX2 (`grafX2`)](https://gitlab.com)**  

  Classic open-source (`GPL-2.0`) 256-color indexed bitmap paint program inspired by Deluxe Paint and Brilliance, purpose-built for authentic retro pixel art and palette cycling.



- **[GIMP (`GNOME/gimp`) & G'MIC (`GreycLab/gmic`)](https://github.com)**  

  Flagship open-source (`GPL-3.0`) raster image editor and pixel-level manipulation suite featuring indexed-palette quantization, nearest-neighbor scaling, `G'MIC` filters, and local AI plugins.



- **[Krita (`KDE/krita`) & Krita AI Diffusion (`Acly/krita-ai-diffusion`)](https://github.com)**  

  Professional open-source (`GPL-3.0`) digital painting and pixel-art suite enhanced with integrated ComfyUI live painting, pixel-art LoRA support, and regional inpainting.



- **[IOPaint (`Sanster/IOPaint`)](https://github.com)**  

  Self-hosted open-source (`Apache-2.0`) AI image inpainting, object removal, outpainting, and upscaling studio powered by `LaMa`, `PowerPaint`, `FLUX`, and `SDXL`.



- **[rembg (`danielgatis/rembg`) & BiRefNet (`ZhengPeng7/BiRefNet`)](https://github.com)**  

  High-accuracy open-source (`MIT`) background removal CLI, Python library, and ONNX model suite for isolating sprites, portraits, and product photos locally.



- **[Real-ESRGAN (`xinntao/Real-ESRGAN`) & Upscayl (`upscayl/upscayl`)](https://github.com)**  

  Leading open-source (`BSD-3-Clause` / `AGPL-3.0`) AI super-resolution frameworks for upscaling illustrations, photographs, and textures cleanly on consumer GPUs.



- **[ImageMagick (`ImageMagick/ImageMagick`)](https://github.com)**  

  Legendary open-source (`ImageMagick License`) CLI and library for programmatic image processing, nearest-neighbor pixel resizing, palette dithering, and sprite-sheet assembly.



- **[Sharp (`lovell/sharp`) & libvips (`libvips/libvips`)](https://github.com)**  

  Ultra-fast open-source (`Apache-2.0` / `LGPL-2.1`) Node.js and C image-processing engines for high-throughput resizing, cropping, format conversion, and pixel buffer manipulation.



- **[OpenCV (`opencv/opencv`) & Pillow (`python-pillow/Pillow`)](https://github.com)**  

  Foundational open-source (`Apache-2.0` / `HPND`) Python and C++ computer-vision and image-processing libraries powering custom pixel-quantization, k-means palette extraction, and filtering pipelines.



### Additional Strong Open-Source Options



- **[Stable Diffusion Pixel-Art LoRAs & ComfyUI (`comfyanonymous/ComfyUI`)](https://github.com)** for reproducible node-based workflows combining `FLUX`/`SDXL` pixel-art LoRAs with nearest-neighbor downscaling and palette clamping.

- **[Texel / TexturePacker Open Alternatives (`FreeTexPacker`)](https://github.com)** and **[Aseprite-to-Godot / Unity Importers](https://github.com)** for automated sprite-sheet packing, atlas JSON generation, and game-engine animation import.

- **[xBRZ / HQx / ScaleFX Pixel-Art Scalers (`libretro/common-shaders`)](https://github.com)** for edge-preserving algorithmic pixel-art upscaling shaders (`xBRZ`, `2xSaI`, `CRT-Royale`) without neural artifacts.

- **[Blockbench (`JannisX11/blockbench`)](https://github.com)** for open-source low-poly 3D modeling paired with pixel-art UV texture painting and voxel workflows.

- **[Darktable (`darktable-org/darktable`)](https://github.com)** and **[IC-Light (`lllyasviel/IC-Light`)](https://github.com)** for non-destructive RAW photo processing and AI portrait/product relighting.
